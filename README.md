# Data Science Roadmap

A self-structured, week-by-week path from Beginner to Specialization in Data Science.

Each week gives you a short list of topics, the resources to use, and one task to prove you learned the topic.

Built and maintained by [Basel Hamdy](https://github.com/BaselHamdy1).

## Who This Is For

- Students who want a clear order to learn data science.
- Self-learners who prefer free resources (videos, courses, articles).
- Arabic and English speakers. Many weeks give an Arabic option.

## How to Use

1. Start at Beginner. Do the weeks in order.
2. For each week, finish the linked resources.
3. Do the task at the end of the week. Do not skip it.
4. Put your task code in your own GitHub repository.
5. Go to the next week only when the task works.

Each week has a **Base resource** and sometimes an **Alternative**. Use one of them. You do not need both.

## What You Will Learn

- **Beginner:** Write Python, use classes, explore data, and track your work with Git.
- **Intermediate A:** Show data in charts and dashboards, query databases, collect data from websites and APIs, and work with dates.
- **Intermediate B:** Prepare features, learn the math behind ML, and study ML models from regression to neural networks, trees, clustering, and recommenders.
- **Advanced:** Learn neural network math from first principles, then PyTorch, CNNs, and transfer learning. Finish with containerized cloud deployment.
- **Specialization:** Start with sequence models. Build the Transformer from scratch. Then study LLM pretraining and fine-tuning, RAG, agents, evaluation, and deployment.

## Tips

- Study a fixed number of hours each week. Keep it steady.
- Write short notes after each resource.
- Do the tasks yourself first. Look at solutions only after you try.
- If a resource is not clear, use the alternative.
