# Data Science Roadmap

[#data-science-roadmap](#data-science-roadmap)

A self-structured, week-by-week path from Beginner to Specialization in Data Science.

## Stages

[#stages](#stages)

- **Beginner** — core programming & data handling (Python, OOP, NumPy, Pandas, Git)
- **Intermediate A** — analysis & tooling (Visualization, SQL, Web Scraping, APIs, Time Series)
- **Intermediate B** — math foundations & classical ML (Feature Engineering, Math for ML, ML, Gradient Boosting, Model Interpretability)
- **Advanced** — deep learning from first principles (autograd, NumPy NN, PyTorch, CNNs, transfer learning, Docker & cloud deployment)
- **Specialization** — Large Language Models (sequence models, Transformers from scratch, pretraining & fine-tuning, RAG, agents, evaluation, deployment)

## How to Use

[#how-to-use](#how-to-use)

Each week lists **Topics → Resources → Task**. Follow the weeks in order within each stage; complete the linked resource(s), then do the task before moving on.
